# Brooklyn 8 天数据集与离线模型参数

基于 `nyc_data/Brooklyn_Hospital_SNF_Data.xlsx` 生成，有真实数据的用真实数据，没有的模拟补齐；同时包含护理人员和紧急度，目标是最小化病人等待。

## 文件

| 文件 | 内容 |
|---|---|
| `brooklyn_8d_staffing_urgency.json` | 完整数据集：人员约束 + 紧急度。当前 main 的算法跑不完（见下） |
| `brooklyn_8d_urgency.json` | 同一批病人和床位，去掉人员约束，约 7 秒跑完，用于离线模型 |
| `Brooklyn_8day_offline_parameters.xlsx` | 离线模型结果和每日参数 |
| `build_dataset.py` | 从 Excel 生成数据集：`python build_dataset.py --xlsx Brooklyn_Hospital_SNF_Data.xlsx --days 8 --scale 3` |
| `offline_run_result.json` | 离线运行的完整输出（dynamic_model.compare） |
| `offline_params.py` | 运行结果 → 每日参数表（需与 Brooklyn_Hospital_SNF_Data.xlsx 放在同一文件夹） |

## 规模

13 家医院、37 家 SNF、181 张空床、147 位病人、8 天（按真实规模 1:3 缩小）。

## 真实 / 模拟

| 字段 | 来源 |
|---|---|
| 医院占用率 | 真实：HCDA，2026-11-18 |
| 每家医院每天去 SNF 人数 | 真实：SPARCS 2024 年均（÷3 缩放） |
| 病人性别、年龄、病情严重度（→ 临床风险）、付款方 | 真实：SPARCS 2024 各医院分布中抽样 |
| SNF 位置、空床、呼吸机床、透析床 | 真实：CMS / 纽约州床位普查（÷3 缩放） |
| SNF 可用护理工时 | 真实：PBJ 2026 Q2 每位住户工时 × 空床数 |
| 病人每天需要的护理时间 | 真实均值：CMS 病例组合预期 4.33 h/天；按严重度 ×0.85–1.25，按 RN 18% / LPN 16% / CNA 65% 分配 |
| SNF 住院天数 | 真实均值 41.7 天（CMS），个人对数正态抽样 |
| 病人在 8 天内何时可出院 | 模拟：均匀分布 |
| 病人住址 | 模拟：所在医院附近 ±2.5 km |
| 转介名单 | 模拟：离家最近、且有对应床型和人手的 3–7 家 SNF |
| 活动能力评分（AM-PAC 6–24） | 模拟：随年龄、严重度下降 |
| 保险授权到期 | 模拟：商业保险全部、其余 30% 有 24/48/72 小时授权窗口 |
| 透析需求 | 模拟：约 3% |
| 床位性别、保险网络 | 无数据：不限 |

| 指标 | Baseline | 离线 CCN |
|---|---|---|
| 总等待 | 1,200 h | 743 h |
| 平均每人等待 | 8.2 h | 5.1 h |

## 参数表（Brooklyn_8day_offline_parameters.xlsx）

| 工作表 | 内容 |
|---|---|
| Summary | 场景和结果对比、说明 |
| SNF_Parameters | 每家 SNF：空床数、8 天入住数、最高占用、**8 天内最少空余床位（可预留的安全量）**、平均空余、护理人员峰值利用率 |
| SNF_Daily_Offline | 每家 SNF 每天（第 0–15 天）：入住、出院、占用、**空余床位**、RN/LPN/CNA 用量和利用率 |
| System_Daily | 全区每天：可出院人数、入住、仍在等待、空余床位（离线 vs Baseline） |
| Hospital_Daily | 每家医院每天：可出院、入住、仍在等待 |
| Offline_Plan | 每个病人的离线安排：哪家 SNF、哪张床、何时入住、等了多久 |

主要发现：
- 空余床位从第 0 天的 160 张降到第 7 天的 38 张，一周后整体已经很紧。
- 8 天内 37 家 SNF 合计"始终空着"的床位只有 38 张，这是不影响离线结果的最大预留量上限。
- 如果按真实人员核对，离线计划中有 345 个"SNF·天"护理需求超过供给，说明加入人员约束后等待会明显增加，人手可能比床位更紧。

## 局限

1. 人员约束没有在求解中执行：当前 main 的算法在这个规模下运行超过 10 分钟（每次检查要遍历病人整个住院期的每个班次，Baseline 还要反复重排），所以先不带人员求解，再事后核对人员。
2. 人员供给按"该 SNF 每位住户的实际工时 × 空床数"估算，是近似。
3. 每日流量来自 2024 年均，不含星期几、节假日波动；空床和人员是 2026 年的快照。
